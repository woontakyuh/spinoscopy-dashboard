# 캐릭터 전신 이미지 파이프라인

대시보드 캐릭터 탭(`/agents/lo` → Character)의 좌측 전신 이미지를 만든다.

## 쓰는 법

```bash
# 벨트 승급 — Gi 사진 한 장만 있으면 된다
npm run character:build -- ~/Dropbox/.../Gi_purple.png --out tak-gi-purple

# 측정만 하고 파일은 안 쓴다 (캔버스에 맞는지 미리 확인)
npm run character:build -- <사진> --check
```

그 다음 `lib/sensei/characterImage.ts` 의 `AVAILABLE_GI_BELTS` 에 벨트를 추가한다.
NoGi 는 래쉬가드라 벨트가 안 보이므로 벨트별로 만들 필요가 없다.

## 왜 얼굴로 맞추나

**키(머리~발끝)로 맞추면 안 된다.** 자세마다 그 길이가 다르기 때문이다.
숙인 자세는 키가 짧으니, 키를 기준으로 맞추면 숙인 사진이 확대되고
서 있는 사진이 축소된다. 실제로 처음에 그렇게 만들었다가 갈아엎었다.

자세와 무관하게 크기가 같은 건 **얼굴**뿐이다. macOS Vision 으로
얼굴 높이와 눈 사이 거리(IPD)를 재서, 둘의 평균으로 배율을 잡는다.
두 기준을 함께 쓰는 이유는 하나가 검출 노이즈를 타도 다른 하나가 잡아주기 때문.

기준 사진(2026-08-25)의 측정값:

| | 얼굴 높이 | 눈 사이 | 키 ÷ 얼굴 |
|---|---|---|---|
| Gi (서 있음) | 102.8 | 37.6 | 10.18 |
| NoGi (숙임) | 114.8 | 40.3 | 7.70 |

키÷얼굴이 10.18 vs 7.70 — 숙인 만큼 24% 짧은 게 맞다. 이 차이를
보정하지 말고 **그대로 두는 것**이 옳다. 우리가 없애야 할 건 촬영 거리
차이(노기가 9.4% 크게 찍혔다)이지 자세 차이가 아니다.

정렬은 **가로 중앙 + 발끝 같은 바닥선**. 그래서 토글하면 사람 크기는
그대로고 자세만 낮아진다.

## 누끼

입력에 알파가 없으면 Vision 으로 자동 추출한다. 다만 **직접 딴 누끼가
있으면 그걸 쓰는 게 낫다** — 자동 추출은 머리카락 경계가 거칠 때가 있다.
현재 쓰는 두 장은 직접 딴 `*-nobg.png` 다.

## 캔버스 기준을 바꿀 때

`reference.json` 의 `canvas`/`target` 을 바꾸면 **기존 이미지도 전부
다시 만들어야 한다.** 안 그러면 벨트마다 사람 크기가 달라진다.

## 파일

- `build.mjs` — 정규화 본체 (sharp)
- `faceinfo.swift` — Vision 얼굴 측정 (첫 실행 시 자동 컴파일 → `.bin/`)
- `cutout.swift` — Vision 누끼 추출 (알파 없는 입력일 때만)
- `reference.json` — 캔버스·목표 얼굴 크기·webp 품질
