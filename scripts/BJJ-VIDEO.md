# 수업 영상 연결

드랍박스 수업 영상을 노션 수련 기록에 붙여서, 대시보드 Training 탭에서
그날 배운 내용을 읽다가 바로 영상으로 넘어갈 수 있게 한다.

```bash
npm run bjj:video-sync -- --dry-run   # 뭘 할지만 본다
npm run bjj:video-sync                # 실제로 쓴다
```

새 수업을 찍어서 `2. 수업영상/YYYY-MM-DD/` 에 넣고 노션에 그날 기록을
만든 뒤 이걸 돌리면 자동으로 붙는다.

## 설계 판단

**조인 키는 날짜다. 이름을 바꾸지 않는다.**
드랍박스 폴더명이 이미 `2026-08-19` 이고 노션 기록도 날짜를 갖는다.
그래서 파일명·폴더명을 하나도 건드리지 않고 붙는다. 폴더명 뒤에 붙는
말(`2026-01-21 김진우 No-gi`)은 무시한다 — 그 정보는 이미 노션의
Instructor/Class 필드에 있다.

**링크는 파일이 아니라 폴더 단위다.**
한 수업에 클립이 평균 4~5개(총 205개)인데, 파일마다 링크를 만들면 205개를
관리해야 하고 정작 어느 클립인지는 열어봐야 안다. 폴더 링크 하나면
드랍박스 뷰어가 썸네일과 재생을 다 해준다.

**같은 날 기록이 여러 건이면 전부에 붙인다.**
영상 폴더는 날짜 단위다. 수업+오픈매트처럼 그날 기록이 둘이면 하나에만
붙을 경우 다른 쪽을 보다가 "영상 없네" 하게 된다.

**`dl=0` 을 유지한다.**
`dl=1` 은 클릭 즉시 다운로드가 시작된다. 클립 하나가 50~500MB라 사고다.
`normalizeShareUrl` 이 이걸 강제한다.

## 노션 속성

없으면 스크립트가 만든다.

| 속성 | 타입 | 내용 |
|---|---|---|
| `Class Video` | URL | 드랍박스 폴더 공유 링크 |
| `Class Video Count` | Number | 폴더 안 클립 개수 |

기존 `Video URL` / `Video Title` 은 **공부 자료**(인스트럭셔널 등)용으로
따로 있다. 수업 녹화와 의미가 달라 섞지 않았다.

## 멱등성

여러 번 돌려도 안전하다. 노션에 같은 링크·같은 개수가 이미 있으면
건너뛰고, 드랍박스에 공유 링크가 이미 있으면 새로 만들지 않고 기존 것을
가져온다. 네트워크 실패는 지수 백오프로 3회까지 되짚는다(IPv6 로 붙었다
간헐적으로 죽는 걸 봐서 IPv4 를 우선한다).

## 자격증명

`DROPBOX_APP_KEY` / `DROPBOX_APP_SECRET` / `DROPBOX_REFRESH_TOKEN`.
원문 PDF 워커가 쓰던 것과 같은 앱이고 `spino-jobs/.env.local` 에 있다.
refresh 토큰 방식이라 만료되지 않는다.

## 노션 기록이 없는 폴더

2024~2025 영상 15개 폴더는 노션 수련 기록이 없다(노션 기록이 사실상
2026년부터다). 링크를 걸 곳이 없어 건너뛴다. 나중에 그날 기록을 만들면
다음 실행 때 자동으로 붙는다.
