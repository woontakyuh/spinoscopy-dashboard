# Demo Mode (dashboard1.takmd.com) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Serve the existing dashboard at `dashboard1.takmd.com` as a demo that shows only Elon + Brian (grid + sidebar), shows the Dakota photo without the greeting speech bubble (weather/date kept), gates access behind a demo-specific password, and blocks hidden agent pages.

**Architecture:** Single Next.js app, single Vercel project. A new `middleware.ts` detects the demo host, enforces the demo password, blocks non-allowed agent pages, and forwards an `x-demo=1` request header. The root layout (server) reads that header and passes a `demoMode` boolean through a client `DemoModeContext`. UI components read `useDemoMode()` to alter rendering. All demo logic keys off pure helpers in `lib/demo.ts`.

**Tech Stack:** Next.js 16 App Router, React 19, TypeScript, Tailwind v4, Vitest.

```ts
// lib/demo.ts
// Pure, framework-free helpers shared by middleware (edge), server layout, and client.
// MUST NOT import React or use "use client" — middleware imports this.

export const DEMO_HOST = "dashboard1.takmd.com"

/** Agent ids visible in demo mode (grid + sidebar). */
export const DEMO_AGENT_IDS = ["elon", "brian"] as const

/** True when the request host is the public demo domain. */
export function isDemoHost(host: string | null | undefined): boolean {
  if (!host) return false
  const bare = host.split(":")[0].toLowerCase()
  return bare === DEMO_HOST
}

/**
 * In demo mode, only Elon and Brian agent pages are reachable.
 * Non-`/agents/*` paths are always allowed.
 */
export function isAllowedAgentPath(pathname: string): boolean {
  if (!pathname.startsWith("/agents/")) return true
  return DEMO_AGENT_IDS.some(
    (id) => pathname === `/agents/${id}` || pathname.startsWith(`/agents/${id}/`),
  )
}

/** Login accepts the main dashboard password OR the demo password. */
export function isValidDashboardPassword(
  input: string,
  dashboardPassword: string,
  demoPassword: string | undefined,
): boolean {
  if (!input) return false
  if (input === dashboardPassword) return true
  return !!demoPassword && input === demoPassword
}
```

### Task 2: Middleware — demo host gate, agent block, x-demo header

**Files:**
- Create: `middleware.ts`

- [ ] **Step 1: Write the implementation**

```ts
// middleware.ts
import { NextRequest, NextResponse } from "next/server"
import { isDemoHost, isAllowedAgentPath } from "@/lib/demo"

// Run on app pages; skip Next internals, static assets, and the auth API
// (login must stay reachable to obtain the cookie).
export const config = {
  matcher: ["/((?!_next/|favicon.ico|api/auth/|.*\\.(?:png|jpg|jpeg|svg|ico|webp)$).*)"],
}

export function middleware(req: NextRequest) {
  const host = req.headers.get("host")

  // Main domain: unchanged behavior (no gate today).
  if (!isDemoHost(host)) {
    return NextResponse.next()
  }

  const { pathname } = req.nextUrl

  // Always allow the login page itself.
  if (pathname === "/login") {
    return NextResponse.next()
  }

  // Demo auth gate: require a valid dashboard-auth cookie.
  const cookie = req.cookies.get("dashboard-auth")?.value
  const dashboardPassword = process.env.DASHBOARD_PASSWORD ?? "spinoscopy2026"
  const demoPassword = process.env.DEMO_PASSWORD
  const authed =
    !!cookie &&
    (cookie === dashboardPassword || (!!demoPassword && cookie === demoPassword))

  if (!authed) {
    const url = req.nextUrl.clone()
    url.pathname = "/login"
    url.searchParams.set("from", pathname)
    return NextResponse.redirect(url)
  }

  // Block hidden agent pages — send back to home.
  if (!isAllowedAgentPath(pathname)) {
    const url = req.nextUrl.clone()
    url.pathname = "/"
    url.search = ""
    return NextResponse.redirect(url)
  }

  // Forward a demo flag header for the server layout to read.
  const headers = new Headers(req.headers)
  headers.set("x-demo", "1")
  return NextResponse.next({ request: { headers } })
}
```
