# Design Reference

이 폴더의 이미지들은 디자인 목업입니다. 구현 시 반드시 참고할 것.

## bjjdashboard.png
메인 대시보드의 디자인 레퍼런스.
- 라이트 모드 기반이지만 다크 모드로 변환하여 구현
- 캐릭터 일러스트가 좌측에 크게 배치
- 이름 + Lv + Guard Player 라벨이 중앙
- 우측에 수련 기록 요약 테이블 (깔끔한 key-value 형태)
- 벨트는 하나의 연속된 띠, 화살표처럼 흐르는 형태
- 스트라이프가 벨트 위에 세로 막대로 표시
- 호버하면 승급/그랄 날짜 툴팁
- 레이더 차트(좌)와 세로 바 차트(우)가 나란히
- 바 차트는 각 카테고리 색상, 막대 위에 숫자 직접 표시
- 하단에 최근 포커스 태그 + 목표 프로그레스

## 디자인 원칙
- "AI가 만든 것 같은" 느낌을 피할 것
- 정보 밀도가 높고 한눈에 파악되는 대시보드
- 의미없는 glow, neon, 그라디언트 효과 금지
- 실제 앱/게임 UI에서 볼 수 있는 자연스러운 레이아웃
- 컬러는 의미 있는 곳에만 사용
