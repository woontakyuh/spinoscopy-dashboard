## 디자인 철학

**"AI가 만든 것 같은" 느낌을 절대 피할 것.**

금지:
- 둥근 모서리 + 그라디언트 배경의 뻔한 카드 나열
- 의미없는 glow, neon, 반투명 효과
- 정보 밀도 없이 빈 공간만 큰 레이아웃
- 모든 요소를 동일한 둥근 카드 안에 넣는 게으른 배치
- 진한 다크 배경에 원색 텍스트의 "게임 UI" 흉내

지향:
- 정보 밀도가 높고 한눈에 파악되는 대시보드
- 실제 앱/게임 UI에서 볼 수 있는 자연스러운 레이아웃
- 컬러는 의미 있는 곳에만 (카테고리 색상, 벨트 색상)
- 여백은 정보 그룹핑 목적으로만 사용
- 레이아웃이 "디자이너가 잡은 것처럼" 보여야 함

## 대시보드 레이아웃 상세 (mockup-dashboard-full.png 참고)

### 상단: 프로필 영역 (3컬럼)

```
┌──────────┬─────────────────────────────┬──────────────────┐
│          │ 여운탁  Lv.14  Guard Player  │ 최근 수련 기록    │
│ 캐릭터    │ 현재: 블루 벨트 3그랄        │                  │
│ 아바타    │                             │ 수련 기간  6년3월 │
│ (도복+벨트)│ Lv.14  ████████ 10/12 XP   │ 기록된 수련    20 │
│          │ Lv.2 → Lv.3               │ 연속      3주    │
│          │                             │ 최장      3주    │
│          │                             │ Gi 비율   80%    │
└──────────┴─────────────────────────────┴──────────────────┘
```

좌측 아바타:
- 약 100-120px 너비
- 도복 입은 캐릭터 일러스트 (AI 생성 이미지 사용 예정)
- 현재 벨트 색상이 도복에 반영
- 둥근 모서리, 배경은 벨트색 미세 틴트
- 목업에서처럼 캐릭터가 서있는 반신 컷

중앙 이름+레벨:
- 이름 큰 글씨 (20-22px, 굵게)
- Lv.14 작은 뱃지 (인라인)
- "Guard Player" 라벨 (pill 형태, 보라색 배경)
- "현재: 블루벨트 3그랄" 서브텍스트
- XP 프로그레스 바 (파란색, 얇은 바)

우측 수련 기록:
- 테이블 형태 (라벨:값 2컬럼)
- 라벨은 연한 색, 값은 밝은 색
- 깔끔한 카드 안에 배치
- 클릭하면 Journal 탭으로 이동

### 벨트 프로그레션 바

```
═══화이트═══╋╋╋╋═══블루═══╋╋╋●═══════퍼플═══════브라운═══════블랙═══
  화이트      블루      퍼플      브라운      블랙
```

핵심 디자인 (mockup-belt-v2.png 참고):
- **하나의 연속된 띠** — 절대 세그먼트로 끊지 않을 것
- 각 벨트 구간은 해당 색상으로 채워짐
- 구간 전환은 화살표/쉐브론 형태로 자연스럽게 (v2 목업처럼)
- 현재까지: 100% 불투명
- 미래 구간: 30% 불투명도 (흐릿하게)
- 스트라이프: 벨트 위의 세로 막대 (대비색)
- 현재 위치: 원형 마커 또는 커서 아이콘
- 호버: 승급 날짜 + 그랄 날짜 툴팁
- 아래에 각 벨트 이름 라벨

### 중단: 레이더 + 바 차트 (2컬럼 나란히)

```
┌──────────────────┬──────────────────────┐
│                  │  32                  │
│     Guard        │  ██████████████ Guard │
│    /    \        │  14                  │
│ LL      Passing  │  ████████ Passing    │
│    \    /        │  0                   │
│  TD   Ctrl       │  Control             │
│    \  /          │  10                  │
│   Finishing      │  ████████ Finishing  │
│                  │  8                   │
│ [레이더 차트]     │  ██████ Takedowns    │
│                  │  0                   │
│                  │  Leg Locks           │
│                  │                      │
│                  │ 가장 유사한 아키타입:  │
│                  │ 🇧🇷 Lucas Leite      │
│                  │ Coyote Half Guard    │
└──────────────────┴──────────────────────┘
```

레이더 차트:
- 6축, 동심원 10/20/30/40
- 블루벨트 기준 최대 40 (프로 100이 아님)
- 선: Gi=파란색, No-Gi=빨간색
- 축 라벨: Guard, Passing, Control, Finishing, Takedowns, Leg Locks

바 차트 (목업 참고 — 세로 막대):
- 6개 세로 막대가 나란히
- 각 막대 색상: Guard=#a855f7, Passing=#22c55e, Control=#f97316, Finishing=#ef4444, Takedowns=#06b6d4, LegLocks=#eab308
- 막대 위에 숫자 직접 표시 (볼드, 각 카테고리 색상)
- 아래에 카테고리 라벨
- 차트 아래에 "가장 유사한 아키타입: 🇧🇷 Lucas Leite — Coyote Half Guard"

## 컴포넌트 스타일 참조

### 뱃지/Pill
- 벨트: 해당 벨트색 배경, 흰 텍스트, border-radius: 20px
- 상태: Registered=green bg, Undecided=amber bg, Completed=default

### 태그
- 카테고리별 색상 배경 (12% 불투명도)
- 텍스트는 해당 카테고리 밝은 톤
- border-radius: 4px, padding: 2px 8px

### 카드
- 얇은 보더 (0.5px)
- 둥근 모서리 (10-12px)
- 미세한 배경 (rgba(255,255,255,0.03))
- 호버: 보더 살짝 밝아짐
